# ntfy Alerts

Home Assistant integration that pushes entity state change notifications to your iPhone via ntfy.sh.

## Installation

1. Add this repository to HACS as a custom integration
2. Install ntfy Alerts from HACS
3. Restart Home Assistant
4. Go to Settings → Devices & Services → Add Integration → ntfy Alerts
5. Install the [ntfy iOS app](https://apps.apple.com/app/ntfy/id1625396347) and subscribe to your personal topic

## Usage

Once configured, open the **ntfy Alerts** panel from the sidebar to manage notification rules visually.

Create rules that watch entity state changes and send push notifications to selected subscribers.
